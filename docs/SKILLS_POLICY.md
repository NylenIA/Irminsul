# Politique skills.sh

`find-skills` sert à découvrir des capacités génériques, mais aucune skill externe ne doit être installée aveuglément.

Avant installation :

1. vérifier le nombre d'installations ;
2. préférer les éditeurs officiels ou connus ;
3. inspecter le dépôt, le `SKILL.md`, les scripts et les permissions ;
4. éviter les skills qui demandent des secrets ou des commandes larges sans nécessité ;
5. tester dans un projet séparé ;
6. verrouiller la version lorsque possible.

Irminsul AI possède ses propres skills Genshin. Les skills externes ne doivent servir qu'à des besoins génériques comme les tests, la création de skills ou la vérification de code.
